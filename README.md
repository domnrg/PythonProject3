# PythonProject3

Приложение позволяет получать и анализировать вакансии с сайта HeadHunter, которые были сохранены в базу данных PostgreSQL.

## Описание

Проект реализует простой консольный интерфейс для работы с вакансиями. Вакансии предварительно собираются с сайта hh.ru и сохраняются в PostgreSQL. Затем можно выполнить различные действия с этими данными.

## Возможности

Приложение позволяет:

1. Вывести список всех компаний и количество вакансий у каждой компании.
2. Вывести список всех вакансий с названием компании, вакансией, зарплатой и ссылкой.
3. Вывести среднюю зарплату по всем вакансиям.
4. Вывести список всех вакансий, у которых зарплата выше средней.
5. Выполнить поиск по ключевому слову в названии вакансии.

## Стек технологий

- Python 3.10+
- PostgreSQL
- psycopg2
- requests

## Пример вывода

1: Вывести список всех компаний и количество вакансий у каждой компании
2: Вывести список всех вакансий с названием компании, вакансией, зарплатой и ссылкой
3: Вывести среднюю зарплату по вакансиям
4: Вывести список всех вакансий, у которых зарплата выше средней по всем вакансиям
5: Вывести список всех вакансий, в названии которых содержатся ключевое слово
0: Выйти
